# 🚀 Job Portal Website

A modern and responsive Job Portal Website built using HTML and CSS. This project is designed to provide a clean and user-friendly interface for job seekers to explore available job opportunities and for recruiters to showcase openings.

---

## 📖 About The Project

The Job Portal Website is a front-end project that simulates a real-world job searching platform. It focuses on creating an attractive UI, responsive layouts, and a seamless user experience using only HTML and CSS.

This project helped strengthen my understanding of:

- HTML5 structure and semantics
- CSS styling and layouts
- Responsive web design
- Flexbox and Grid
- UI/UX design principles
